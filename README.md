# XCAT-3

Project webpage for **XCAT-3: A Comprehensive Library of Personalized Digital Twins Derived from CT Scans**.

Live at: [https://xcat-3.github.io](https://xcat-3.github.io)

## Features

- **Phantoms tab** — Interactive 3D phantom viewer with demographic filtering. Browse 2,500+ computational phantoms derived from real CT scans.
- **Motion tab** — Parametric respiratory motion explorer. Two knobs control diaphragm excursion (5–25 mm) and rib rotation scale (0.1–1.0), loading precomputed breathing animation GIFs for 25 parameter combinations per patient case.

## Paper

Dahal, L. et al. *XCAT 3.0: A comprehensive library of personalized digital twins derived from CT scans.* Medical Image Analysis, 2025.
[https://doi.org/10.1016/j.media.2025.103636](https://doi.org/10.1016/j.media.2025.103636)
